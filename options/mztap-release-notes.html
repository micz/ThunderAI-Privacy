ThunderAI Privacy Release Notes

Version 1.0.0 - 29/10/2026

  • Local personal-data masking and response restoration for ThunderAI through processing API v1.
  • WebGPU/CPU inference, chunked long inputs, isolated sessions, progress and cancellation.
  • Settings in two steps: download the local model first, then turn on the protection. The switch is the same as the Use ThunderAI Privacy option of ThunderAI, and cannot be turned on before the model is ready.
  • The model is downloaded in the background, so the download can also be started from ThunderAI (or by its administrator policy) and goes on after closing the settings. Access to Hugging Face is now requested at installation.
  • The model cannot be deleted while the protection is on. Opt-in sensitive diagnostics.
